# `nn` Overview

## Functional
Neurite's [`nn.functional` (abbreviated as `nnf`)](functional.md) provides GPU accelerated functional interfaces for working with tensors.

## Models
The [`nn.models` module](models.md) provides a collection of a few pre-defined neural network architectures for various tasks.

## Modules
The [`nn.modules` module](modules.md) contains building blocks for constructing neural networks, including layers, loss functions, and optimizers.
